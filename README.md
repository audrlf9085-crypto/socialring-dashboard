# 소셜링 광고본부 브랜드 대시보드

- `index.html` : 전체 브랜드 허브 (브랜드 카드 · 브랜드별 비교 · 성과 표)
- `brand.html?b=브랜드코드` : 브랜드별 상세 대시보드
  - 브랜드 코드: dinsee(딘시) · plantude(플랜튜드) · ibedu(아이비에듀) · vitablossom(비타블로썸) · heritage(국가유산주간) · cafegm(카페공명)
- `config.js` : 브랜드 이름·색·구글 시트 주소. **고칠 파일은 이것 하나뿐이에요.**
- `data/브랜드코드/` : 2026-11-16 기준 저장본 데이터와 콘텐츠 썸네일

## 구글 시트 실시간 연결

1. 브랜드 구글 시트에서 **파일 → 공유 → 웹에 게시**를 누릅니다.
2. '문서 전체'가 아니라 **탭 하나**를 고르고, 형식은 **쉼표로 구분된 값(.csv)**으로 둔 뒤 게시합니다.
3. 나온 주소를 복사해 `config.js`에서 그 브랜드의 `content: ''` 따옴표 안에 붙여 넣습니다.
4. 저장소에 `config.js`를 다시 올리면 1–2분 뒤 반영됩니다.

| 칸 | 게시할 탭 | 연결 가능한 브랜드 |
|---|---|---|
| content | 콘텐츠 성과 분석 (raw data) | 모든 브랜드 (국가유산주간 제외: 성과 탭 없음) |
| plan / ads / seeding | 콘텐츠 발행안 / 메타광고(잠재고객DB) / 인플루언서 시딩 | 카페공명 백업 양식 |

플랜튜드·아이비에듀·비타블로썸·국가유산주간·딘시의 발행안과 광고 탭은 시트 양식이 서로 달라서
저장본(`data/`)을 씁니다. 새 데이터가 쌓이면 시트를 엑셀로 내려받아 다시 정리하면 돼요.

⚠ '브랜드 현황'(계정·비밀번호) 탭이나 인플루언서 연락처가 있는 탭은 절대 게시하지 마세요.
⚠ GitHub Pages 주소는 링크를 아는 누구나 볼 수 있어요.
